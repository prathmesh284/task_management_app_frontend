# Frontend – Task Management System

This frontend application provides the user interface for the
Task Management System. It allows users to authenticate, manage
tasks, and add comments based on their roles.

## Tech Stack
- React
- JavaScript
- Axios
- CSS

## Features
- User authentication (Admin / Employee)
- Task creation, update, and status tracking
- Role-based UI access
- Comment system for tasks

## Setup Instructions
1. Install dependencies  
   npm install

2. Start development server  
   npm run dev
